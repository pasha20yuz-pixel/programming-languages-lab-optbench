# Исследование оптимизаций компилятора MSVC (C/C++)

Лабораторная работа по дисциплине «Языки программирования».  
Исследование влияния флагов оптимизации компилятора MSVC (`cl.exe`) на размер исполняемого файла и структуру ассемблерного кода на примере тестового бенчмарка `OPTBENCH.c`.

---

## 📊 Размеры исполняемых файлов (.exe)

| Режим компиляции | Флаг компилятора | Размер бинарного файла (.exe) | Описание |
| :--- | :--- | :--- | :--- |
| **Без оптимизации** | `/Od` | **118 272 байт** (~115.5 КБ) | Отладочный режим, работа с переменными через стек |
| **Оптимизация по размеру** | `/O1` | **117 248 байт** (~114.5 КБ) | Минимизация размера бинарного файла |
| **Оптимизация по скорости** | `/O2` | **117 248 байт** (~114.5 КБ) | Максимизация скорости выполнения |

---

## 📌 Основные выводы

1. **Уменьшение размера бинарника:** Использование оптимизаций (`/O1`, `/O2`) уменьшило размер бинарного файла на **1 024 байта** по сравнению с неоптимизированной сборкой (`/Od`).
2. **Сходство режимов /O1 и /O2:** На данном синтетическом тесте размеры бинарников при `/O1` и `/O2` совпали из-за аналогичного набора базовых трансформаций компилятора (устранение избыточных инструкций работы со стеком, свёртка констант, удаление неиспользуемого кода). Из-за идентичности ассемблерного кода подходам оптимизации, детальное сравнение листингов в отчёте проводилось между режимами `/Od` и `/O2`.
3. **Использование регистров:** В оптимизированном коде переменные и счётчики циклов активно распределяются по регистрам процессора (`eax`, `ecx`, `edx`, `ebx`, `esi`), минимизируя обращения к оперативной памяти.
4. **Снижение мощности операций:** Компилятор автоматически заменяет "тяжёлые" операции (умножение, сдвиги) на инструкции за 1 такт АЛУ (например, `lea eax, [ecx+ecx]`).

## 📁 Структура репозитория

* `OPTBENCH.c` — исходный код программы на C.
* `OPTBENCH_O0.cod` — ассемблерный листинг без оптимизаций (`/Od /FAcs`).
* `OPTBENCH_O2.cod` — ассемблерный листинг с оптимизацией по скорости (`/O2 /FAcs`).
* `optbench_O0.exe` — исполняемый файл без оптимизации.
* `optbench_O2.exe` — исполняемый файл с оптимизацией по скорости.
* `Лаб1 ЯП.docx` — официальный отчёт по лабораторной работе.

## 🛠 Команды компиляции (PowerShell / MSVC Native Tools)

Компиляция без оптимизации:
```powershell
cl /Od /FAcs OPTBENCH.c /Fe:optbench_O0.exe
Rename-Item OPTBENCH.cod OPTBENCH_O0.cod
```
Компиляция с оптимизацией по скорости:

```powershell
cl /O2 /FAcs OPTBENCH.c /Fe:optbench_O2.exe
Rename-Item OPTBENCH.cod OPTBENCH_O2.cod
```
