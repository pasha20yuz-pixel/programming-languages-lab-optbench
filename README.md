# Исследование оптимизаций компилятора MSVC (C/C++)

Лабораторная работа по исследованию влияния флагов оптимизации компилятора MSVC (cl.exe) на размер исполняемого файла и структуру ассемблерного кода.

## Размеры исполняемых файлов (.exe)

| Режим компиляции | Флаг компилятора | Размер бинарного файла (.exe) |
| :--- | :--- | :--- |
| **Без оптимизации** | /Od | **118 272 байт** (~115.5 КБ) |
| **Оптимизация по размеру** | /O1 | **117 248 байт** (~114.5 КБ) |
| **Оптимизация по скорости** | /O2 | **117 248 байт** (~114.5 КБ) |

## Выводы
1. Использование оптимизации (/O1, /O2) уменьшило размер бинарного файла на 1024 байта по сравнению с неоптимизированной сборкой (/Od).
2. На данном синтетическом тесте размеры бинарников при /O1 и /O2 совпали из-за сходного набора базовых оптимизаций (устранение лишних инструкций работы со стеком, свертка констант).
3. В оптимизированном коде переменные активно распределяются по регистрам процессора (eax, ecx, edx, ebx), убирая избыточные обращения к памяти.

## Структура репозитория
* OPTBENCH.c — исходный код программы на C;
* OPTBENCH_O0.cod — ассемблерный листинг без оптимизаций (/Od);
* OPTBENCH_O2.cod — ассемблерный листинг с оптимизацией по скорости (/O2).
